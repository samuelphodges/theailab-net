Professor Chun  
For the first Mini-Project, we were tasked with using Claude code to redesign the course’s webpage. In order to do this, I split my work into two different sections. The first section of my work was using the prompts given to us for finding any problems Claude saw within the webpage itself. The second section of my work used my own prompts to redesign the style and layout of the website.   
	For the first section, I strictly used the code prompts given to us in the email. I wasn’t yet fully comfortable with the system and I wanted to make sure I did this correctly. These prompts included doing the original fork and repo of the website, critiquing the codebase, and creating a list of tasks (problems) that Claude found necessary to change. Once Claude created a report of potential changes in a list of highest to lowest importance, I then reviewed it and implemented the changes. This is a very important step in the process as it allows me to confirm that Claude is not hallucinating or making unnecessary edits to the webpage redesign. These changes primarily involved removing dead or unused lines of code, content-drift regression tests, and other cleanup and housekeeping edits. These changes were “underground” changes as they do not affect the visual look and feel of the website. However, they were important to ensure the webpage works correctly.   
	The second section is when I began to take more control of how the webpage looks visually. I started by prompting Claude a second time to make sure there were no mechanical flaws within the website. Upon confirmation I then asked it for visual redesign options, while highlighting that I was leaning towards doing a Kenyon style match (color palette and typeface from Kenyon’s homepage). This part was very interesting as Claude gave me three different examples of what the website would look like given three different new styles. Upon inspecting them, I eventually settled on the “Kenyon match” as I felt it looked the best and matched the creative style I was seeking. Once implemented, I then prompted Claude for a final website structure check to confirm there were no underlying issues with the website, and it confirmed everything was working smoothly.   
	 If given the opportunity, there is a future implementation to the website I feel would be interesting. I know that some websites have chatbots attached to them and I think this could be helpful in a course’s website. It would allow you to ask questions regarding the content of the page such as finding due dates or requirements for certain assignments. I feel this could be useful as it would take away the time looking through the syllabus and course schedule. It could also ideally route you to specific sections of the website without having to spend time looking for them. Overall, I really enjoyed this project as it allowed me to learn the proper workflow for using Claude as well as how to prompt it in order to accomplish desired tasks. I think this was a great, interactive way to learn the system while having a cool finished product in the end.
